# Home Collection

Private garage app for the car and motorcycle collection: Cars, Bikes, Service ledger and Costs.

- Static `index.html`, deployed on Vercel (preset Other, no build command, output directory `.`).
- Data in Supabase project `home-collection` (`vehicles`, `service_records`, `editors`, storage bucket `media`).
- Anyone with the link can view; only emails in `editors` can sign in and edit.
- Keys 1–4 jump between tabs.
